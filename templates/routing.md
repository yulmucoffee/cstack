## Code review (cstack)

For any request to review code, a diff, a branch, a commit or a pull request, in any wording or language ("review this PR", "code review", "check my changes", "PR 리뷰", "코드 검토"), use the `cstack` skill in `review` mode, even when another review skill or command also matches. If the user also asks for a built-in review command such as `/code-review`, `/security-review` or `/review`, cstack runs it as an extra pass. Requests to babysit, merge or ship a PR also go through cstack.
